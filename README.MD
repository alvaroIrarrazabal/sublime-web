# Sublime Web

> Modular web platform for businesses.

---

## Overview

Sublime Web is a modular platform designed to build modern, scalable and reusable websites for different types of businesses.

The project focuses on creating high-quality digital solutions using a reusable component architecture, allowing new business websites to be developed quickly while maintaining a consistent user experience.

---

## Vision

Build a professional platform capable of serving multiple business sectors through reusable components and a shared architecture.
