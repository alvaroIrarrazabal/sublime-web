# ADR-002 - Tailwind CSS

## Status

Accepted

## Context

The project requires a fast, reusable and scalable styling solution to build multiple business websites from a shared component library.

## Decision

Use Tailwind CSS as the primary styling framework together with SCSS for global styles and advanced customizations.

## Alternatives Considered

- CSS
- SCSS only
- Bootstrap
- Angular Material

## Consequences

### Positive

- Faster UI development
- Highly reusable components
- Easy customization for different business sectors
- Excellent responsive support

### Negative

- Requires learning utility-first CSS
- Initial setup is more complex than plain CSS
