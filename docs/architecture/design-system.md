# Sublime Web Design System

## Objetivo

Crear una identidad visual consistente y reutilizable para todos los productos desarrollados en Sublime Web.

---

# Principios

## 1. Consistencia

Todos los componentes deben mantener el mismo lenguaje visual.

## 2. Reutilización

Nunca desarrollar dos veces el mismo componente.

## 3. Accesibilidad

Todos los componentes deben ser utilizables mediante teclado y cumplir buenas prácticas de contraste.

## 4. Responsive First

Cada componente debe funcionar correctamente en:

- Mobile
- Tablet
- Desktop

## 5. Simplicidad

Preferimos interfaces limpias y fáciles de usar.

Toda decisión deberá documentarse mediante ADR.
